PDFSwitch Windows 本机连接器 1.1.1

1. 请完整解压到 D 盘（或其他非 C 盘）的独立文件夹。
2. 双击 PDFSwitch-Connector.exe，保留窗口。
3. 在自动打开的页面点击“回到网站并配对”，或复制六位配对码到网站。
4. 浏览器询问时，允许 PDFSwitch 网站访问本机。
5. 选择文件、转换、查看 PDF 和核对报告。

支持 Windows 10/11 64 位，无需单独安装 Python。
Office/WPS、Illustrator、CorelDRAW 需在当前 Windows 用户下安装、激活并完成首次运行。
不同软件版本的自动化接口和复杂效果仍需以实际样本核验。

如果网站尚未发布或浏览器不允许连接本机，可在连接器页面点击“使用本机网页”。
网页和转换功能相同，导出的 PDF 保存在本连接器目录的“PDF输出”文件夹，沿用源文件名（例如 设计稿.cdr → 设计稿.pdf）。
同名文件自动加 (2)、(3) 等序号，不覆盖已有 PDF。重试导出也会保留上一次的 PDF。
源文件副本、页面预览和核对报告仍保存在 data 子文件夹。
Word 导出遵循“打印背景颜色和图像”设置，修复旧文档隐藏背景被导出为蓝底的问题。
程序只监听 127.0.0.1:18765，不向局域网开放端口。
关闭程序窗口将停止连接器；请等待当前转换结束再关闭。
重启连接器后，重新配对；配对码 10 分钟有效，成功使用后更新。

运行文件、文档、报告和可配置临时目录均位于解压目录。
桌面设计软件、操作系统和浏览器仍可能产生其自身的内部缓存。
程序未添加开机任务、系统服务、注册表协议或浏览器扩展。

Microsoft Office/WPS 的实际转换取决于已安装版本。
不承诺任意文件绝对无损；自动核对、人工参考对比、内嵌 PDF 原样保留和未完成均分别标明。
每页视觉差异低于 2% 忽略；页数、尺寸和文字检查独立判断。

常见问题：
- 无法连接：先确认程序窗口未关闭，在浏览器打开 http://127.0.0.1:18765/connect。
- 端口占用：检查已有连接器窗口。不要同时运行多个副本。
- 提示 C 盘：把整个文件夹解压到 D 盘后运行。
- 原生引擎失败：先在原软件中手动打开文件，完成激活或弹窗后再重试。
- 本机网页的“下载连接器”按钮不适用；已有连接器无需再次下载。
