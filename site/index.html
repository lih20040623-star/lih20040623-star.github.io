03 / 使用指南
  1. 01
    下载并解压

    将 Windows 连接器压缩包完整解压到 D 盘的独立文件夹。无需另装 Python。

  2. 02
    运行本机连接器

    双击 PDFSwitch-Connector.exe，保留程序窗口。点击打开的页面中的“回到网站并配对”。

  3. 03
    连接，开始转换

    确认六位配对码并连接。浏览器询问时允许本网站连接本机，然后选择文件。

支持哪些软件？文件在哪里？

支持调用本机 Microsoft Office、WPS、Illustrator 和 CorelDRAW。LibreOffice 可用于兼容转换。v1.1.0 起，导出的 PDF 集中保存在连接器目录的“PDF输出”文件夹，沿用原文件名；同名自动加序号。源文件副本和核对报告仍保存在 data 文件夹，各台电脑的任务互不共享。

已打包 PDF 页面视觉核对工具；仅当原软件能成功采集源页面时，才可能自动核对通过。AI 内嵌 PDF 原样保留、人工参考对比和未完成核对均单独标明。每页视觉差异低于 2% 忽略，页数、尺寸与文字仍单独检查。

连接失败怎么办？

确认连接器窗口仍在运行，并使用当前 Chrome 或 Edge。在连接弹窗中点击“获取本机配对码”，配对码 10 分钟有效且使用后更新。若浏览器不支持网站访问本机，可以在连接器页面选择“使用本机网页”，使用同一套功能。

当前连接器适用于 Windows 10/11 64 位。电脑没有 D 盘时，可以解压到其他非 C 盘。桌面软件可能产生自己的系统缓存，连接器的文件、日志和临时目录放在解压位置。
