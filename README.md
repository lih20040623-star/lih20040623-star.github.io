# PDFSwitch

连接当前 Windows 电脑上的设计与办公软件，转换 PDF，并逐页核对。

网站入口：**https://lih20040623-star.github.io/**

## 使用方法

1. 从网站或本仓库的 Releases 下载 `PDFSwitch-Windows.zip`。
2. 完整解压到 D 盘或其他非 C 盘，双击 `PDFSwitch-Connector.exe`。无需另装 Python。
3. 在打开的页面点击“回到网站并配对”，确认六位配对码。
4. 浏览器询问时，允许本网站访问本机，然后选择要转换的文件。

程序窗口需要保持打开。浏览器无法连接本机时，可在连接器页面点击“使用本机网页”。

每台电脑使用自己安装并激活的 Illustrator、CorelDRAW、Microsoft Office 或 WPS。转换、源文件副本、PDF 和报告保存在该电脑连接器目录的 `data` 子文件夹，网站不接收文档，各台电脑的任务互不共享。

## 核对范围

保留原项目的原生软件导出与核对功能。每页视觉差异低于 2% 忽略；页数、尺寸和文字检查独立判定。自动核对通过、参考核对一致、内嵌 PDF 原样保留、发现差异、核对未完成分别显示，不承诺任意文件绝对无损。

48 项原引擎测试、10 项连接测试，以及打包程序的两页 PDF 上传、参考核对、6 个 PNG 预览和下载流程已通过。不同电脑和 Office/WPS/设计软件版本仍需用实际样本确认。

## 本机连接

连接器仅监听 `127.0.0.1:18765`，不向局域网或公网开放。每次运行生成独立访问令牌，网站通过短期配对码连接。配对码 10 分钟有效，成功使用后更新；重启连接器后重新配对。

连接器的文件和可配置缓存写入解压位置。Windows、浏览器和桌面软件仍可能产生自己的系统内部缓存。

`site/` 是网页；`connector/` 是连接器及转换引擎源代码。第三方组件许可证和来源见连接器分发包及 `connector/licenses/`。Office/WPS、Illustrator、CorelDRAW 不包含在下载包内。
